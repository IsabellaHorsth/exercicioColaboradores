Métodos de Consulta Derivados

Um Guia Visual para Spring Data JPA

O Spring Data JPA permite criar consultas ao banco de dados de forma automática, apenas nomeando os métodos da sua interface de repositório de maneira inteligente. Isso elimina a necessidade de escrever consultas SQL ou JPQL na maioria dos casos.

Anatomia de um Método de Consulta

find...By+NomeDoAtributo+(Condição)
  • Prefixo (`find...By`): Indica a ação de busca. Pode ser `read...By`, `get...By`, `query...By`, etc.
  • Atributo (`NomeDoAtributo`): O nome exato de um campo da sua classe de entidade (ex: `Nome`, `Email`, `Idade`).
  • Condição (`Condição`): Palavras-chave que definem o filtro da sua consulta (ex: `Containing`, `GreaterThan`).

💡 Resumo Rápido das Palavras-chave

Palavra-chave O que faz
Containing Verifica se o campo contém o valor especificado (similar ao `LIKE %valor%`).
StartingWith Verifica se o campo começa com o valor especificado (similar ao `LIKE valor%`).
EndingWith Verifica se o campo termina com o valor especificado (similar ao `LIKE %valor`).
IgnoreCase Ignora se os caracteres são maiúsculos ou minúsculos na comparação.
GreaterThan, LessThan Busca por valores maiores/menores que o parâmetro fornecido.
Between Busca por valores que estão entre dois parâmetros (inclusivo).
Top, First Limita o número de resultados retornados pela consulta.

🚀 Outros Exemplos Úteis

1. ID maior que um valor

Busca entidades cujo `id` é maior que o valor fornecido.

List<Produto> findByIdGreaterThan(Long id);

Exemplo de Retorno (JSON):


[
  { "id": 101, "nome": "Produto A" },
  { "id": 102, "nome": "Produto B" }
]

2. Busca entre Datas

Encontra registros entre uma data de início e uma data de fim.

List<Usuario> findByDataNascimentoBetween(Date inicio, Date fim);

Exemplo de Retorno (JSON):


[
  { "nome": "Ana", "dataNascimento": "1995-03-15" },
  { "nome": "Carlos", "dataNascimento": "1996-08-22" }
]

3. Nomes que começam com...

Encontra usuários cujo nome começa com "Jo".

List<Usuario> findByNomeStartingWith(String prefixo);

Exemplo de Retorno (JSON):


[
  { "nome": "João" },
  { "nome": "José" },
  { "nome": "Jonas" }
]

4. Combinando Palavras-chave

Busca por nome que contenha "joao", ignorando maiúsculas/minúsculas.

List<Usuario> findByNomeContainingIgnoreCase(String termo);

Exemplo de Retorno para a busca "joao":


[
  { "nome": "Joao da Silva" },
  { "nome": "Maria Joao" },
  { "nome": "JOSE JOAO" }
]

5. Limitando Resultados (Top)

Busca os 3 funcionários com os maiores salários.

List<Funcionario> findTop3ByOrderBySalarioDesc();

Exemplo de Retorno (JSON):


[
  { "nome": "Diretor", "salario": 25000 },
  { "nome": "Gerente Sênior", "salario": 18000 },
  { "nome": "Arquiteto de Software", "salario": 15000 }
]

6. Consultando Atributos Aninhados

Localiza usuários pela cidade do seu endereço.

List<Usuario> findByEnderecoCidade(String cidade);

Exemplo de Retorno para "São Paulo":


[
  { "nome": "Alice", "endereco": { "cidade": "São Paulo" } },
  { "nome": "Pedro", "endereco": { "cidade": "Campo Grande" } }
]
